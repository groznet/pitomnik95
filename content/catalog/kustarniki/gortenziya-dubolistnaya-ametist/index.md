Кустарник высотой до 180 см. Куст приобретает форму шара. Белые бутоны распускаются, становятся насыщенно-розовыми цветками, к осени они приобретают пурпурный цвет. Цветение с июня по октябрь. Листья нетипичные для гортензии, больше напоминают по форме хризантему. Кусты очень густые, отлично подходят для создания живой изгороди.
