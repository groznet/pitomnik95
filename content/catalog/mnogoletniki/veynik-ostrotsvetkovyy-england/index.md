Многолетнее компактное растение высотой до 120 см, диаметром 60-70 см. Листья зеленые с желтой полосой в центре. Образует постепенно расползающуюся эффектную кочку. Цветет колосьями пшеничного цвета в июле-августе. Растение, отлично подходящее для сада в природном стиле для среднего плана. Этот вейник не расползается, не разваливается, нарастает умеренно. Колосья в начале сезона зеленоватые, потом становятся пшеничного цвета, который сохраняется до зимы. Хорошо растёт на открытых солнечных участках с плодородными, умеренно влажными почвами. Неприхотлив, зимует без укрытия. Используется в качестве вертикальных акцентов.
